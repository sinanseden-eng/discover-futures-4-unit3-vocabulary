# Between the Lines

An illustrated Unit 3 vocabulary Word Bank for Oxford Discover Futures 4. Students choose a cover, guess from the clue, and reveal the word with a definition, illustration, useful phrases, and an example. Revealed words become titles on the shelves. Progress is saved in the current browser tab and survives a refresh.

## Run locally

Run `python3 -m http.server 8000 --directory dist` from the repository root, then open http://localhost:8000.

## Publish on Netlify

Import this GitHub repository into Netlify and select the `main` branch. The included `netlify.toml` publishes `dist/`. The site needs no build command, environment variables, or student sign-in.
